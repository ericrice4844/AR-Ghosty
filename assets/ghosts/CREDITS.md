# Ghost sprite credits

The photographic ghost sprites in this folder are heavily modified versions of the openly licensed photographs below: cut out, regraded, dirtied, with eyes and mouths altered. Modifications by the AR-Ghosty project. `tools/make_sprites.py` rebuilds them from the originals (save each source as the file name shown).
